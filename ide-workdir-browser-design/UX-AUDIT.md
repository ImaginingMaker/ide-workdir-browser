# IDE Workdir Browser — UI/UX 验收记录

> 本文记录当前 OpenPencil 设计稿重塑后的验收口径。产品能力以
> [PRD](../ide-workdir-browser-code/docs/PRD.md) 为准，真实桌面行为以
> [Computer Use 回归归档](../ide-workdir-browser-code/docs/computer-use-regression.md) 为准。

## 本轮重塑结论

设计稿已从旧 HTML/历史 OpenPencil 状态切换为“以最新软件界面为基准”的生成式设计资产：

- 43 个源状态覆盖真实应用主要界面、边缘状态和响应式状态。
- 7 个分类画布用于设计评审和交付。
- App 图标和 10 个 Agent 图标来自真实应用资产目录，并在生成时转换为 PNG data URL，避免
  OpenPencil 显示图片占位图。
- 布局 token 与 Sass 中的真实尺寸保持一致。

## 覆盖范围

### 1. 浏览工作台

- 标准窗口、宽窗、窄窗和最小窗口均有状态稿。
- 侧边栏展示 10 个默认 Agent，包含品牌图标、配置路径和文字状态。
- 图标、列表、分栏三种视图按当前组件结构表现。
- 隐藏文件半透明、长文件名两行截断、分页截断和 Agent 隔离均有单独状态。
- Inspector 覆盖空态和文件信息态。

### 2. 文件预览

- 文档标签栏位于工具栏下方，显示浏览器标签、文件标签和 Agent 作用域。
- 代码文件使用代码块预览。
- Markdown 展示“预览/源码”模式切换，并表现渲染态。
- 图片预览、大文件不可预览和二进制/不支持预览均有明确状态。
- 暗色预览单独覆盖。

### 3. 搜索与文件操作

- 搜索结果使用主内容区工作台，包含关键词、结果数、扫描数量和范围 chip。
- 当前设计表现默认“当前目录”搜索，不展示未开放的全局范围切换。
- 无结果和达到上限均给出明确反馈。
- 右键菜单、Finder 拖入复制、复制确认、冲突策略和撤销通知按当前文件操作流程覆盖。
- 跨 Agent 粘贴状态按真实 UI 表现为右键菜单中的“粘贴/粘贴到此处”入口，以及后续复制确认弹窗。

### 4. 设置工作台

- 设置作为独立工作台，不渲染浏览工具栏、文档标签、路径栏或状态栏。
- 设置侧边栏包含 IDE 管理、外观、高级、关于和“返回浏览器 Esc”。
- IDE 管理覆盖 10 个默认 Agent、路径编辑、启用开关和默认 Agent。
- 外观覆盖主题、强调色、缩放、字体、隐藏文件和文件夹图标三预设。
- 高级覆盖符号链接、搜索上限、读取超时、分页阈值和还原默认设置。
- 重置确认弹窗说明影响范围，并明确不会删除磁盘文件。
- 关于页覆盖当前版本、手动稳定版检查、新版本状态和“查看并下载”；不伪装为自动安装。

### 5. 图标系统

- 文件类型图标覆盖 `archive`、`binary`、`code`、`config`、`database`、`document`、`file`、
  `folder`、`image`、`json`、`key`、`markdown`、`table`、`terminal`、`text`。
- 文件夹图标三套预设在外观设置与设计系统页均可见。
- Agent 图标使用真实 SVG 资产，不再依赖旧的 6 Agent PNG 集合。

## 质量检查

- `node scripts/generate.mjs` 成功生成 43 个源状态。
- `node scripts/consolidate.mjs` 成功合并为 7 个分类画布。
- `ide-workdir-browser.op` 可通过 JSON 解析，页面数量为 7。
- `ide-workdir-browser.op` 中 PNG image 节点计数为 147，SVG image 节点计数为 0。
- 操作消息浮层已按真实 `notification-host → notification-stack → notification-toast` 结构建模，
  位于内容区右下角 18px 安全边距内，并包含撤销、关闭和底部倒计时条。
- A13 拖入层使用 `932×786` 完整文件舞台，不再因 `fill_container` 计算错误缩成横线；文件操作
  弹窗遮罩同样覆盖完整舞台并居中 `420×210` 卡片。
- F41 右键菜单计算尺寸为 `224×250`，定位为舞台内 `220,150`，包含两条真实分隔线；运行时
  已将“移到废纸篓”改为选中项可用并进入二次确认，空白区域菜单仍保持禁用。
- Windsurf/Kiro 等路径不可用项不再降低整行透明度；侧边栏保留色点加文字，设置页卡片只显示状态
  文字，与真实实现一致。
- B17 的启用开关不再由路径状态推导；10 个默认 Agent 均保持启用，Windsurf/Kiro 仍单独显示
  “路径不可用”。
- 打包应用与 A01 对照后，标准窗搜索框改为按工具栏容器计算，Agent 品牌图标按展开
  `24/28px`、折叠 `20/24px` 的图形/容器尺寸对齐。
- 旧 `560 × 420` 最小窗复核暴露出双面板恢复时的布局挤压；`760px` 仍会裁剪工具栏左侧操作，
  当前基线最终提升为 `900 × 540`，E37 状态稿和新的 Computer Use 结果以回归归档为准。
- `tokens.json` 可通过 JSON 解析。
- 生成脚本和合并脚本均通过 `node --check`。
- 7 个分类画布执行 `design:refine` 均为 0 项自动修复；lint 仅保留同色结构容器、异尺寸工具栏
  控件和禁用态文字的启发式 warning/info，没有结构错误。
- B23 已使用 `0.1.0` 真实版本口径，并与 React 关于页的检查按钮、成功状态和外链入口对齐。
