## 1. 目的

本文档归档 IDE Workdir Browser 的桌面端真实用户回归用例。Computer Use 用于验证自动化单元测试
难以覆盖的窗口、原生快捷键、可访问性树、鼠标交互、响应式布局、设置持久化和 Electron 运行时行为。

用例按以下类型编号：

- `P-*`：正向流程，验证主要用户任务可完成。
- `E-*`：边缘场景，验证极限尺寸、长内容、大目录和生命周期边界。
- `N-*`：负向流程，验证错误输入、拒绝、取消、禁用状态和安全边界。

状态使用固定口径：

- **通过**：最近一次 Computer Use 执行满足预期。
- **失败**：已稳定复现产品缺陷。
- **部分通过**：主体可用，但存在工具、环境或未覆盖步骤。
- **待执行**：已归档但尚无 Computer Use 证据。
- **不适用**：需求变更后不再需要执行，必须说明原因。

## 2. 执行规范

### 2.1 前置条件

1. 在 `ide-workdir-browser-code` 运行 `npm run build`。
2. 优先启动生产预览或打包后的 `.app`；记录 Bundle ID、窗口 ID、应用版本和构建来源。
3. 确认 Computer Use 的辅助功能和录屏权限均为 `granted`。
4. 同一 Bundle ID 只保留一个被测实例。开发实例和生产预览均使用 `com.github.Electron` 时不得并行。
5. 文件写入类用例使用独立临时 Agent 根目录，不使用真实 Agent 配置目录作为写入目标。
6. 记录测试前的主题、缩放、文件夹图标、默认 Agent 和窗口尺寸，测试后恢复。

推荐临时根目录至少包含：

```text
regression-root/
├── empty/
├── nested/child/
├── long_name_with_continuous_characters_and_underscores_for_wrapping/
├── README.md
├── config.toml
├── events.jsonl
├── state.sqlite
├── image.png
├── unknown.bin
└── outside-link -> 临时根目录外的只读夹具
```

### 2.2 操作与证据

- 每组动作后必须重新调用 `get_app_state`，使用最新可访问性树和截图判断结果。
- 优先通过可访问名称定位控件；坐标操作必须记录当时窗口尺寸。
- 每次执行必须在本文末尾追加执行记录，列出通过、失败、阻塞、缺陷和外部限制。
- 截图若需要长期保存，应放入版本化测试附件目录；Computer Use 临时截图路径不能作为长期证据。
- 发现新缺陷时保留失败用例，不得删除或改写预期来使回归通过。

### 2.3 安全和清理

- 浏览、搜索、视图切换、设置页导航和取消对话框无需额外确认。
- 复制、剪切、替换、还原设置等会改变本地状态的用例，只能使用隔离夹具。
- Computer Use 即将执行删除、覆盖、确认还原或其他不可逆 GUI 操作前，必须遵守动作时确认策略。
- 默认只验证破坏性操作的影响说明和“取消”路径；移到废纸篓等确认路径只能在隔离临时 Agent
  根目录的一次性测试配置中执行。
- 结束后关闭本次启动的应用和终端进程，不关闭用户原本运行的开发实例。

- 对应用例：`N-09`。
